# Tugas-Membikin-Soal-
 Soal 1 (KelulusanMahasiswa)
 Seorang mahasiswa mengikuti sebuah mata kuliah. Dosen memberikan aturan sebagai berikut:
 1. Mahasiswa dinyatakan Lulus jika nilai ≥ 75
 2. Mahasiswa dinyatakan Tidak Lulus jika nilai < 75

 Buatlah sebuah program yang:
 1. Meminta input nilai mahasiswa dari user
 2. Mengecek apakah mahasiswa lulus atau tidak
 3. Menampilkan hasil

 Input: Sebuah nilai integer (nilai mahasiswa)
 Output: Lulus atau Tidak Lulus

Soal 2 (SoalDiskon)

 Sebuah toko memberikan promo kepada pelanggannya. Aturannya adalah:
 1. Jika total belanja ≥ 100000, maka pelanggan mendapatkan diskon 10%
 2. Jika total belanja < 100000, maka tidak mendapat diskon
 
 Buatlah program yang:
 1. Meminta input total belanja dari user
 2. Menghitung diskon (jika ada)
 3. Menghitung total yang harus dibayar
 4. Menampilkan hasil

 Input: Sebuah bilangan integer (total belanja)
Output
 1. Total belanja awal
 2. Besar diskon
 3. Total yang harus dibayar

 Soal 3 (SoalGaji)
 Seorang karyawan di sebuah perusahaan mendapatkan gaji berdasarkan jumlah jam kerja yang ia lakukan setiap hari. Perusahaan menetapkan bahwa setiap 1 jam kerja dihargai sebesar Rp10.000.

 Buatlah sebuah program yang dapat:
 1. Meminta input jumlah jam kerja karyawan dari user
 2. Menghitung total gaji yang diperoleh
 3. Menampilkan hasil gaji

 Input: Sebuah bilangan integer yang menyatakan jumlah jam kerja
 Output: Total gaji karyawan dalam bentuk angka

 Soal 4 (SoalParkir)
 Sebuah tempat parkir menerapkan tarif berdasarkan lama parkir kendaraan. Setiap kendaraan dikenakan biaya sebesar Rp2.000 per jam.
 
 Buatlah program yang:
 1. Meminta input lama parkir (dalam jam) dari user
 2. Menghitung total biaya parkir
 3. Menampilkan total biaya yang harus dibayar

 Input: Sebuah bilangan integer yang menyatakan lama parkir (jam)
 Output: Total biaya parkir

 Soal 5 (SoalUmur)
 Dalam kehidupan sehari-hari, seseorang dikategorikan sebagai dewasa atau belum dewasa berdasarkan umur.

 Aturan yang digunakan:
 1. Jika umur ≥ 18 tahun → Dewasa
 2. Jika umur < 18 tahun → Belum Dewasa

 Buatlah program yang:
 1. Meminta input umur seseorang dari user
 2. Menentukan status umur (dewasa atau belum dewasa)
 3. Menampilkan hasil

 Input: Sebuah bilangan integer yang menyatakan umur
 Output: "Dewasa" atau "Belum Dewasa"

 Soal 6 (SoalRataRata)
 Seorang mahasiswa memiliki 3 nilai dari mata kuliah yang berbeda. Untuk mengetahui performa akademiknya, diperlukan perhitungan rata-rata nilai.
 
 Buatlah program yang:
 1. Meminta input 3 nilai mahasiswa dari user
 2. Menghitung rata-rata dari ketiga nilai tersebut
 3. Menampilkan hasil rata-rata
 
 Input: 
 Tiga buah bilangan integer:
 1. Nilai 1
 2. Nilai 2
 3. Nilai 3
Output: Nilai rata-rata dalam bentuk desimal

 Soal 7 (SoalListrik)
 Sebuah rumah menggunakan listrik setiap bulan yang dihitung berdasarkan jumlah pemakaian energi listrik dalam satuan kWh (kilowatt-hour).

 Perusahaan listrik menetapkan tarif sebagai berikut:
 Setiap 1 kWh dikenakan biaya sebesar Rp1.500

 Buatlah program yang:
 1. Meminta input jumlah pemakaian listrik (kWh) dari user
 2. Menghitung total biaya listrik yang harus dibayar
 3. Menampilkan hasil biaya

 Input: Sebuah bilangan integer yang menyatakan jumlah pemakaian listrik (kWh)
 Output: Total biaya listrik yang harus dibayar

 Soal 8 (SoalTerbesar)
 Dalam suatu program, sering diperlukan untuk membandingkan dua buah bilangan untuk mengetahui mana yang lebih besar. Buatlah program yang:
 1. Meminta input dua buah bilangan dari user
 2. Membandingkan kedua bilangan tersebut
 3. Menentukan bilangan yang terbesar
 4. Menampilkan hasil

 Input: 
 Dua buah bilangan integer:
 1. Bilangan pertama
 2. Bilangan kedua
 Output: Bilangan yang terbesar dari kedua input

 Soal 9 (Soal Faktorial)
 Dalam matematika, faktorial dari suatu bilangan 𝑛 (ditulis 𝑛!) adalah hasil perkalian semua bilangan bulat positif dari 1 sampai 𝑛.
 Contoh:
 5!=5×4×3×2×1=120
 3!=3×2×1=6

 Buatlah program yang:
 1. Meminta input sebuah bilangan dari user
 2. Menghitung nilai faktorial dari bilangan tersebut
 3. Menampilkan hasil faktorial

 Input: Sebuah bilangan integer (n)
 Output: Nilai faktorial dari bilangan tersebut

 Soal 10 (SoalPerkalian)
 Dalam matematika dasar, tabel perkalian digunakan untuk membantu perhitungan. Program ini akan menampilkan hasil perkalian suatu bilangan dari 1 sampai 10.
 
 Buatlah program yang:
 1. Meminta input sebuah bilangan dari user
 2. Menampilkan tabel perkalian dari bilangan tersebut (dari 1 sampai 10)
 3. Menampilkan hasil dalam format yang rapi

 Input: Sebuah bilangan integer (n)
 Output: Tabel perkalian dari bilangan tersebut (1–10)
